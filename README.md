# 德胧 AI Native · 手势体验站 (Delonix Gesture Lab)

> 用摄像头 + 机器学习，把手部动作变成「遥控手机 / 空间」的指令。
> 一个自包含、可离线运行、面向酒店行业的**手势即服务 (Gesture-as-a-Service)** 演示资产。

[🌐 在线体验（GitHub Pages）](https://chaoliuzhu.github.io/delonix-handtrack-lab/)

---

## 一句话定位

把 MediaPipe 手部关键点识别 + WebGL 实时画面扭曲，封装成一个**手机浏览器直接打开**的体验站，让观众用手势隔空「牵动屏幕」「触发动作」。它不是玩具——它验证了酒店行业里一批**零接触交互**场景的技术可行性。

## 手部动作到底能「遥控」什么？

手势识别只是输入端，真正的价值在于**动作映射**。按能力分层：

### L0 · 系统 / 媒体（浏览器即可，无需业务后端）
| 能力 | 说明 |
|---|---|
| 全屏 / 退出全屏 | 演示、放映一键铺满 |
| 截图 / 录屏保存 | 把当前画面（含特效）存为 PNG |
| 暂停 / 继续 | 冻结视频或界面，便于讲解 |
| 前后摄像头切换 | 自拍 ↔ 后置 |
| 手电筒 | 暗场指引 |
| 媒体播放 / 暂停 / 上下首 | 控制背景音乐、欢迎视频 |
| 音量 / 亮度增减 | 环境自适应 |

### L1 · 页面 / 应用交互
翻页 / 下一张（PPT、相册、文档）、滚动 / 回到顶部、选中 / 确认 / 返回、打开菜单 / 切换 Tab、缩放聚焦（图片 / 地图放大某点）、双指捏合缩放平移。

### L2 · 语义动作（映射到业务意图）
截图即分享（客房相册、社交）、发起通话 / 呼叫服务、打开地图导航、下单 / 加购 / 签到、切换模式（阅读 / 睡眠 / 影院 / 勿扰）。

### L3 · 空间 / 特效（演示「手牵动屏幕」的体感）
水波纹、空间黑洞、粒子、聚焦放大、镜像扭曲——以手部位置为波源 / 奇点实时驱动。

### L4 · 外部设备 / 后端联动（需 bridge / API）
智能客房 IoT（灯 / 窗帘 / 空调 / 电视 / 音箱）、中控大屏 / 数字标牌、服务机器人调度、PMS / 客控系统写事件（无障碍呼叫落单）。

> 本体验站当前实现 L0–L3 的真实动作（全屏 / 截图 / 暂停 / 特效切换）+ 可配置的 L2/L4 语义映射（以文案 + 触发记录呈现）。接入真实后端时，只需把 `GESTURE_HANDLERS` 里的桩函数替换为 IoT / PMS / 服务调度调用即可。

## 手势 → 动作映射表

| 手势 | 几何判定 | 当前真实动作 | 可扩展为 |
|---|---|---|---|
| 🖐️ 张开 | 四指伸直 | 全屏 | 呼出主菜单 / 开灯 |
| ✌️ 比耶 | 食中伸直、其余收 | 截图下载 | 翻页 / 呼叫礼宾 |
| ✊ 握拳 | 五指收拢 | 暂停 / 继续（边沿触发） | 勿扰 / 紧急 SOS |
| 🤏 捏合 | 拇指–食指距 < 0.05 | 循环切换特效 | 缩放聚焦 / 切换场景 |

**判定原则**：采集路不翻转、直接送 MediaPipe；只有显示与 shader 波源用镜像坐标，故「手牵动屏幕」在你看来位置完全正确，且 4 种旋转对称手势判定不受镜像影响。

**稳定性设计**：事件总线要求同一手势连续稳定 4 帧才触发，触发后冷却 700ms，避免一个握拳被连发；暂停采用「松开手再握拳」边沿触发，杜绝抖动锁死。

## 酒店行业增益场景（可扩展想象）

1. **无接触客房控制**——隔空调灯 / 窗帘 / 电视 / 空调，免触屏更卫生，疫情后仍是刚需。
2. **宴会 / 会议演讲控场**——演讲者隔空翻页、放大、暂停，解放双手；德胧 MICE 销售可直接拿它向客户演示「科技感」。
3. **大堂数字标牌互动**——路人不需触摸即可与欢迎屏互动，提升科技感与停留时长。
4. **无障碍服务呼叫**——行动不便 / 老年客人用手势即可呼叫客房服务 / 前台 / SOS，落单到 PMS。
5. **康养 / 亲子互动**——大堂手势小游戏，家庭客群尤其是儿童互动，增强记忆点。
6. **防疫清洁度营销点**——「零接触」作为品牌卫生承诺的可视化证据。
7. **静默呼叫**——深夜 / 会议中不便于出声时，用手势无声呼叫服务。
8. **AI Native 品牌资产**——给业主 / 客户 / 投资人展示德胧「手势即服务」的科技叙事。
9. **数据回流**——脱敏的手势交互热力，用于优化数字标牌布局与动线。
10. **员工免触操作**——工程 / 客房人员戴手套时用手势操作平板系统，免摘手套。

## 场景模式（体验站内切换）

顶部「场景」一行可在 5 种酒店语境间切换，**同一组手势被赋予不同关联事项**：

- **通用演示** — 标准映射，用于功能验证
- **智能客房** — 开灯 / 客房相册 / 勿扰 / 场景切换
- **宴会放映** — 全屏放映 / 翻页 / 暂停演讲 / 氛围特效
- **大堂欢迎** — 欢迎互动 / 呼叫礼宾 / 结束 / 欢迎特效
- **无障碍呼叫** — 客房服务 / 前台 / 紧急 SOS / 切换呼叫类型

每次触发都会写入底部「触发记录」面板（手势 + 关联事项 + 场景 + 时间戳），呼应「关联事项可追踪」。

## 技术架构

- **手部识别**：MediaPipe Tasks Vision `HandLandmarker`，GPU delegate，`VIDEO` 模式，单帧 21 关键点，支持双手。
- **手势判定**：基于 21 点几何规则（指尖–腕部径向距离、拇指–食指距），纯前端、零依赖。
- **特效**：WebGL fragment shader 把摄像头画面当纹理做实时像素扭曲（水波纹 / 黑洞），手部中心为波源 / 奇点；WebGL 不可用时自动降级纯 2D（功能不白屏，仅无特效）。
- **可配置**：`GESTURE_CONFIG`（手势表）+ `SCENARIOS`（场景语义）+ `GESTURE_HANDLERS`（动作注册表），新增手势 / 场景只需加表项，检测逻辑不动。
- **国内网络适配**：MediaPipe JS 库 + WASM 运行时 + 模型 `hand_landmarker.task` **全部本地化**，不依赖任何海外 CDN（jsdelivr / storage.googleapis.com），国内手机直连无墙。

## 部署与自托管

**① GitHub Pages（已启用）**
直接访问 https://chaoliuzhu.github.io/delonix-handtrack-lab/

**② 任意静态托管**
推到 Vercel / Netlify / 任意带 HTTPS 的静态托管即可，手机扫码体验。

**③ 本地**
```bash
cd handtrack-lab
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080  （localhost 属安全上下文，可用摄像头）
```
> ⚠️ `file://` 直接双击打开拿不到摄像头——必须在 `https` 或 `localhost` 安全上下文运行。

**④ 中低端机降级**
把 `index.html` 里 `delegate:"GPU"` 改为 `"CPU"`、摄像头 `width:640` 降到 `480`，可显著提升帧率。

## 扩展指南（接真实业务）

打开 `index.html`，定位第二段脚本的 `GESTURE_HANDLERS`：

```js
const GESTURE_HANDLERS = {
  fullscreen(){ /* 替换为：呼出客房控制面板 API */ },
  pause(){ /* 替换为：写 PMS 勿扰状态 */ },
  cycleEffect(){ /* 替换为：切换智能场景 */ },
  screenshot(){ /* 替换为：上传客房相册 / 推送给礼宾 */ }
};
```

配合场景表的 `map` / `toast` 文案，即可把演示桩换成真实 IoT / PMS / 服务调度调用。
